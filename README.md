# geo-measure

一个最小可用的 **GEO（Generative Engine Optimization）测量工具**。

用来回答一个问题：**AI 在回答用户问题时，会不会提到你、引用你的网站。**

不依赖任何 GEO 商业工具，只用几个 API。

## 为什么做这个

市面上讲 GEO 的很多，给数据的很少。

我们自己做了一轮测量，40 个问题、4 个引擎、连续 12 天，结果在这里：

**https://yhzxai.com/report-20261118.html**

一句话结论：**内容被搜索引擎收录 ≠ 被 AI 引用**。中间有很长的延迟。

这个仓库是那套测量方法的开源版本，你可以拿去测自己的项目。

## 它测什么

对每个问题，向 AI 引擎提问，记录：

| 字段 | 含义 |
|---|---|
| `question` | 问题原文 |
| `mentioned` | AI 有没有提到你的品牌 |
| `mentionCount` | 提了几次 |
| `competitorMentions` | 提到了哪些竞品 |
| `citations` | AI 引用了哪些 URL |
| `ownCitationCount` | 引用了你官网几次 |

然后算三个指标：

```
提及率        = 提到你的题数 / 总题数
自然题提及率  = 自然题里提到你的比例      ← 核心指标
自有引用率    = 引用你官网的次数 / 总引用次数
```

## 关键设计：品牌题 vs 自然题

**这是最重要的一点。**

```
品牌题  直接问品牌名
        「XX 公司是做什么的？」
        → 测「AI 认不认识你」（知名度）

自然题  只问需求，不提品牌
        「成都有哪些做企业 AI 培训的？」
        → 测「AI 推不推荐你」（生意）
```

**两个必须分开测。**

我们的实测数据：

```
品牌题提及率   100%   （AI 完全认识我们）
自然题提及率     0%   （AI 从不推荐我们）
```

**如果只测品牌题，会得出「效果很好」的错误结论。**

## 用法

### 1. 准备问题集

```json
{
  "name": "my-project",
  "version": 1,
  "prompts": [
    { "id": "b1", "question": "XX 公司是做什么的？", "branded": true },
    { "id": "b2", "question": "XX 公司适合什么场景？", "branded": true },
    { "id": "n1", "question": "成都有哪些做企业 AI 培训的？", "branded": false },
    { "id": "n2", "question": "企业 AI 培训怎么验收？", "branded": false }
  ]
}
```

**建议**：5-7 个品牌题 + 20-35 个自然题。

### 2. 配引擎

```bash
export DEEPSEEK_API_KEY=sk-xxx
export DASHSCOPE_API_KEY=sk-xxx
```

### 3. 跑测量

```bash
python measure.py --prompts prompts.json --engine deepseek --out result.json
```

### 4. 看结果

```bash
python report.py --input result.json
```

输出 Markdown 报告，含提及率、竞品排行、引用来源 Top N。

## 四个常见坑

**1. 只问一次**

AI 有随机性。同一道题问两次，答案可能不同。

**每题至少问 2 次，看趋势不看单点。**

**2. 问题集变了**

这次 17.5%，下次 22%，以为进步了。其实是问题不一样。

**固定问题集、固定引擎，只改时间。**

**3. 混淆「提到」和「推荐」**

问「XX 公司是做什么的」，AI 当然会回答。这是品牌题。

真问题是：**不问品牌名的时候，AI 会不会提到你。**

**4. 不看引用来源**

只统计「提没提」，不知道问题出在哪。

**引用 URL 是唯一能指导行动的数据。**

## 实测数据（2026-11）

我们的项目，12 天，4 次测量：

| 日期 | 提及率 | 品牌题 | 自然题 | 自有引用 |
|---|---|---|---|---|
| 11-06 | 15.0% | 85.7% | 0% | 0 |
| 11-13 | 17.5% | 100% | 0% | 0 |
| 11-17 | 17.5% | 100% | 0% | 0 |
| 11-18 | 17.5% | 100% | 0% | 0 |

**12 天发了 40+ 条内容，自然题提及率一次都没动。**

完整的分析写在：**https://yhzxai.com/report-20261118.html**

## 结论：GEO 的真实节奏

```
第 1 周      内容铺出去，什么都看不到
第 2-4 周    搜索引擎开始收录
第 1-3 个月  AI 检索库可能开始抓到
第 3 个月后  才有资格谈「效果」
```

如果有人跟你说「两周见效」，让他给数据。
